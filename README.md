# Instagram Shift Pause

Расширение управляет наиболее видимым видео Instagram:

- автоматически выбирает видеопоток максимального доступного качества, включая 4K и 8K;
- `Shift` — поставить видео на паузу или продолжить воспроизведение;
- `Пробел` — плавно перейти к следующему посту или видео в режиме Reels;
- `[` / `Х` — показать предыдущий слайд активного поста;
- `]` / `Ъ` — показать следующий слайд активного поста;
- нажать или удерживать `,` / `Б` — перематывать видео назад с шагом 3 секунды;
- удерживать `.` / `Ю` — воспроизводить видео со скоростью 1,75×;
- отпустить `.` / `Ю` — вернуть обычную скорость 1×.

Иконка `Play`, которую Instagram добавляет поверх поставленного на паузу видео, удаляется из DOM.
При замене источника видео последний кадр остаётся видимым до загрузки
первого кадра нового качества, поэтому чёрного мигания быть не должно.

Кэши манифестов и медиассылок ограничены по размеру. Контроллер качества не использует
постоянный таймер и освобождает `MediaSource`, сетевые запросы и видеобуферы при удалении видео.

## Установка

1. Откройте в Chrome `chrome://extensions`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите эту папку.
5. Перезагрузите уже открытую вкладку Instagram.

Горячие клавиши не срабатывают во время ввода текста в полях.
